ВАРИАНТ 2 - ГОТОВО ДЛЯ GITHUB PAGES

1. Загрузите содержимое этой папки в корень репозитория.
2. В GitHub откройте Settings > Pages.
3. Выберите Deploy from a branch, ветку main и папку / (root).
4. Сохраните настройки и дождитесь публикации.

Важно: папку assets нужно загрузить целиком. Форма отправляет заявки
через FormSubmit на batuninivan3@gmail.com. При первой заявке сервис
может прислать письмо для подтверждения адреса получателя.
