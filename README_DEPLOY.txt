Платежный сценарий
- Кнопки оплаты находятся в карточках тарифов.
- Сайт запрашивает почту и телефон, затем создает платеж через отдельный API.
- API работает на сервере в /opt/codex-agent-task.
- Текущий публичный HTTPS-адрес API выдан бесплатным Quick Tunnel Cloudflare.

ВАЖНО ПЕРЕД БОЕВЫМ ЗАПУСКОМ
1. Quick Tunnel подходит для тестов, но не имеет гарантии постоянного адреса и доступности.
   Для постоянного приема оплат нужен стабильный домен или постоянный туннель.
2. Четыре юридических документа опубликованы постраничными изображениями с
   водяным знаком через legal-viewer.html. Публичных DOCX и прямых ссылок на
   скачивание нет. Полностью исключить снимки экрана технически невозможно.
3. Сейчас используется тестовый терминал Т-Банка. После прохождения тестов банк выдаст
   рабочий TerminalKey и пароль, которые нужно заменить только в серверном .env.
